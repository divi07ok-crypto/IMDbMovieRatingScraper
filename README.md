# IMDb Movie Rating Scraper

A Python-based web scraping project that extracts IMDb movie ratings using Selenium and analyzes the collected data with Pandas.

## Introduction

The IMDb Movie Rating Scraper is a Python project developed to automate the collection of movie information such as rank, title, release year, and rating.

Selenium WebDriver is used for web scraping, while Pandas is used for storing and analyzing the collected movie data.

## Objectives

- Automate movie data collection
- Extract movie rank, title, year, and rating
- Store the collected data in CSV format
- Analyze movie ratings using Pandas
- Display the movie data through a dashboard

## Technologies Used

- Python
- Selenium
- Pandas
- WebDriver Manager
- Streamlit
- HTML

## Features

- Automated movie data scraping
- Movie rank extraction
- Movie title extraction
- Release year extraction
- Rating extraction
- CSV data storage
- Movie rating analysis
- Interactive dashboard
